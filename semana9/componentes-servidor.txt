Sistema operativo:
Es el software principal que gestiona el hardware de la máquina. Proporciona el entorno básico y las interfaces de red necesarias para que Node.js pueda ejecutarse.

Node.js:
Es un entorno de ejecución para JavaScript en el lado del servidor. Permite construir herramientas de red y servidores web rápidos, eficientes y altamente escalables.

Aplicación server.js:
Es el archivo con el código fuente escrito por el desarrollador. Define las rutas (endpoints) y la lógica de negocio que responde a las peticiones de los usuarios.

Puerto:
Es una compuerta lógica o interfaz virtual en el sistema operativo para canalizar el tráfico de red. Permite que el servidor escuche de forma exclusiva en una dirección concreta (como el puerto 3000).

Logs:
Son registros de texto que documentan cronológicamente los eventos, accesos y errores del sistema. Son indispensables para que el equipo técnico monitoree la estabilidad y diagnostique fallos.
